# athron98.github.io

The **Athron98 / BrokenLight** ecosystem hub — built with [Astro](https://astro.build) + Tailwind CSS, deployed to GitHub Pages.

## Routes

- `/` — Main hub & ecosystem backlink distribution
- `/clarity` — Clarity framework showcase (+ `/clarity/docs` versioned documentation)
- `/nobo` — Nobo showcase (note boards / snippet manager)
- `/tuner` — Tuner showcase (instrument tuning app)

## Commands

| Command           | Purpose                     |
| ----------------- | --------------------------- |
| `bun install`     | Install dependencies        |
| `bun run dev`     | Local dev server            |
| `bun run build`   | Production build to `dist/` |
| `bun run preview` | Preview the build           |
| `bun run check`   | Typecheck (astro check)     |
| `bun run lint`    | Lint with ESLint            |
| `bun run format`  | Format with Prettier        |
